# Resumes

Put your resume PDFs here. The selector picks a variant per role:

| File | Used for |
|---|---|
| `resume_apm.pdf` | Associate Product Manager, APM, PM Intern |
| `resume_product_analytics.pdf` | Product Analyst, Growth Analyst, Product Strategy |
| `resume_ai_product.pdf` | AI Product Manager, AI Product Analyst |
| `resume_business_analyst.pdf` | Business Analyst, Data Analyst, Product Ops |
| `resume_general.pdf` | Fallback when nothing else matches |

If you don't have tailored variants yet, copy the same file into all five names —
`list_resume_variants` reports which slots are filled.

These files stay local and are excluded from version control.
