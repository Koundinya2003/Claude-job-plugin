Guardrailsstops where judgement starts

It prepares. You decide.

default

Discovery

Searches, validates, scores, ranks. Never submits anything.

mode: application

Application

Prepares applications and fills non sensitive fields, then stops.

Always comes back to you

Legal declarationsCompensationEEO and demographicsWork authorizationRelocationAnything bindingPayment details

Will not

  • Invent a recruiter, email, job ID, URL or company
  • Fabricate experience, metrics or certifications
  • Claim a submission that was not confirmed
  • Submit a duplicate application
  • Bypass CAPTCHA, MFA or bot protection
  • Report an unreachable site as processed

Check it/plugin
